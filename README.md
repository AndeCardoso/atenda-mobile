# Atenda Mobile

Este é um projeto de aplicativo móvel desenvolvido com React Native. O objetivo do projeto é criar uma interface de usuário atraente e fácil de usar para os usuários.

## Estrutura do Projeto

O projeto é dividido em diferentes pastas e arquivos, cada um com sua própria responsabilidade:

* `android`: contém os arquivos de configuração e código específicos para a plataforma Android.
* `ios`: contém os arquivos de configuração e código específicos para a plataforma iOS.
* `src`: contém o código-fonte do aplicativo, incluindo componentes, telas e lógica de negócios.
* `app`: contém os componentes e telas do aplicativo.
* `components`: contém os componentes reutilizáveis do aplicativo, como botões, campos de texto, etc.
* `styles`: contém os estilos CSS do aplicativo.

## Tecnologias Utilizadas

* React Native: framework para desenvolvimento de aplicativos móveis.
* JavaScript: linguagem de programação utilizada para desenvolver o aplicativo.
* React: biblioteca de componentes para desenvolver interfaces de usuário.
* Redux: biblioteca para gerenciamento de estado do aplicativo.
* React Native Safe Area Context: biblioteca para gerenciamento de áreas seguras na tela.

## Instalação e Execução

Para instalar e executar o projeto, siga os passos abaixo:

1. Clone o repositório Git do projeto.
2. Instale as dependências do projeto utilizando o comando `npm install` ou `yarn install`.
3. Execute o comando `npx react-native run-android` ou `npx react-native run-ios` para executar o aplicativo no emulador ou dispositivo físico.
